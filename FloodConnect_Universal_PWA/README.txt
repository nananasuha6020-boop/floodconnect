FLOODCONNECT UNIVERSAL WEB APP (PWA)

Tujuan:
- Satu URL / satu QR untuk Android dan iPhone.
- Pengguna scan QR dan app terus buka dalam browser.
- Android boleh pilih Install App / Add to Home screen.
- iPhone: Safari > Share > Add to Home Screen.

Hosting paling mudah:
1. Pergi https://tiiny.host/
2. Upload fail ZIP ini.
3. Pilih nama link/subdomain.
4. Publish.
5. Salin URL website yang diberi.
6. Buat QR daripada URL WEBSITE itu (bukan URL halaman upload/hosting).

PENTING:
- Pengguna yang scan QR tidak perlu akaun hosting.
- Ini ialah Web App/PWA, bukan APK iOS.
- Data demo disimpan dalam browser telefon (localStorage), jadi laporan tidak dikongsi antara telefon.
